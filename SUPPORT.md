# Support and community

For a specific product, first consult that repository's README, existing issues, and release notes.

- **Bug or feature suggestion:** Open a focused issue in the affected project's repository, if issues are enabled. Include reproducible steps and redacted logs when useful.
- **Security concern:** Follow the project's security policy or [our default security guidance](SECURITY.md). Never disclose sensitive findings in a public issue.
- **General exchange:** [r/MAYHEMClub](https://www.reddit.com/r/MAYHEMClub/) is a community space, not a guaranteed support desk.
- **Discord:** The KeilerHirsch Labs community hub is being prepared; an official invite link will follow.

Projects under development do not have implied production support or response-time commitments.
